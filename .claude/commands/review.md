# /review — the morning pass

1. Read `run/<newest>/summary.md` and `shortlist.json`.
2. Walk through each drafted response with the user, one at a time. For each:
   show the opportunity, then the draft, and ask whether to send, edit or drop.
3. Edit the drafts in place as the user reacts.

Be direct about weak drafts. If one was written from a thin opportunity, say so
rather than letting them send it — you have the context on why it scored where
it did.

## Tune the profile as you go

The most valuable output of this pass is not the applications, it is what the
user's reactions reveal. When they reject something, ask why and offer to write
it into `profile.yaml`:

- "Not interested in crypto" → `avoid.tech`
- "Too junior" / "too senior" → tighten `wants`
- "This one is exactly right" → the vocabulary in it belongs in `interested_in`

A profile tuned over a week of mornings makes every later night better. Say this
out loud the first few times so the user knows the corrections are worth making.
